⚡ SISTEMAS DE POTENCIA

ALTA PROBABILIDAD

1. Flujo de Carga (Power Flow)

▼

Concepto Fundamental:

El flujo de carga determina el estado de operación de un sistema de potencia en régimen permanente.

Ecuaciones de Flujo de Potencia: Pᵢ = Σⱼ₌₁ⁿ |Vᵢ||Vⱼ||Yᵢⱼ|cos(θᵢⱼ - δᵢ + δⱼ)
Qᵢ = -Σⱼ₌₁ⁿ |Vᵢ||Vⱼ||Yᵢⱼ|sin(θᵢⱼ - δᵢ + δⱼ)

Demostración:

Paso 1: Corriente en barra i: Iᵢ = Σⱼ₌₁ⁿ YᵢⱼVⱼ

Paso 2: Potencia compleja: Sᵢ = VᵢIᵢ*

Paso 3: Expandiendo en forma polar y separando partes real e imaginaria

💡 Analogía: Imagina el flujo de carga como el sistema de agua de una ciudad. Las barras son tanques, las líneas son tuberías, y necesitas calcular la presión (voltaje) y el flujo (potencia) en cada punto.

2. Estabilidad del Sistema

▼
Ecuación de Oscilación: M(d²δ/dt²) + D(dδ/dt) = Pₘ - Pₑ

Criterio de Áreas Iguales:

∫[δ₀ a δₘₐₓ](Pₘ - Pₑ)dδ = 0
Área de aceleración = Área de desaceleración
💡 Analogía: La estabilidad es como andar en bicicleta. Si das un pedalazo muy fuerte (falla), puedes perder el equilibrio. El criterio de áreas iguales es compensar ese impulso con una frenada controlada.

3. Máxima Transferencia de Potencia

▼

Demostración DC:

Pₗ = Vₜₕ²Rₗ/(Rₜₕ + Rₗ)²

dPₗ/dRₗ = 0 → Rₗ = Rₜₕ

Pₘₐₓ = Vₜₕ²/(4Rₜₕ)

Demostración AC:

Zₗ = Zₜₕ* (impedancia conjugada)

4. Teorema de Fortescue - Componentes Simétricas

▼

Demostración:

a = 1∠120°, a² = 1∠240°, a³ = 1

V₀ = (1/3)(Vₐ + Vᵦ + V𝒸)

V₁ = (1/3)(Vₐ + aVᵦ + a²V𝒸)

V₂ = (1/3)(Vₐ + a²Vᵦ + aV𝒸)

5. Factor de Potencia

▼
FP = cos(φ) = P/S
Qc = P(tanφ₁ - tanφ₂)
💡 Analogía: Imagina un mesero llevando una bandeja. La potencia activa es la comida útil, la reactiva es el esfuerzo de mantener la bandeja equilibrada.

6. Máquina Síncrona

▼
E = V + I(Rₐ + jXₛ)
P = (EV/Xₛ)sin(δ)
💡 Analogía: El generador síncrono es como una bicicleta con pedales fijos. La velocidad (frecuencia) está determinada por la cadena (campo magnético rotatorio).

7. Motor de Inducción

▼
s = (nₛ - n)/nₛ
Z₂' = R₂'/s + jX₂'
